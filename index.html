What it does

One orb. The whole machine.

01

Real voice conversation

Hands-free loop: it speaks answers as they stream in, hears you start talking, stops itself, and replies. Barge in mid-sentence. It listens. Manual mic and per-answer replay included.

mic → whisper → answer → speech, ~1s to first word

02

Sees your screen

Ask it to do things inside real apps: Settings, Word, installers. It reads the screen with OCR and clicks like you would.

03

Writes programs

Describe it, pick language and folder, get complete working files, from single scripts to multi-file projects.

04

Files & terminal

Read PDFs, Word, Excel, transcribe audio/video, run shell commands. Paths you give are honored exactly.

05

Remembers

Chat history on your disk, to-do list, notes, one-click quick-job buttons you define yourself.

Install

Three steps. No admin. Reversible.

  1. 1

    Download the ZIP

    One file, ~155 MB, versioned and hash-published on this page. Extract it anywhere.

  2. 2

    Run the installer

    Double-click Install-Syncopx.bat. It copies the app to your profile, adds Start Menu (+ optional Desktop) shortcuts, and autostart only if you say yes. Full list below.

  3. 3

    Pick your AI provider

    Open Settings, choose Ollama (local, free) or paste your own Gemini, Groq, OpenRouter… key. Keys stay encrypted on your PC. Nothing is bundled.

What the installer registers

  • %LOCALAPPDATA%\Syncopx\app — program files
  • HKCU\Software\Syncopx — InstallDir, Version
  • HKCU\…\Run\Syncopx — autostart, only with your yes
  • Start Menu shortcut (+ Desktop if asked)

Uninstall anytime with the bundled Uninstall.bat — it removes all of the above. Your chats and keys are kept unless you say wipe.

About the SmartScreen warning

Syncopx has no paid publisher certificate yet, so Windows may show “Windows protected your PC” on first run. That is expected: click More info → Run anyway. Verify the ZIP first with the SHA-256 hash above.

FAQ

Straight answers.

Is it really a ZIP, not a setup.exe?

Yes, deliberately. An installer EXE without a paid publisher certificate triggers worse warnings than a ZIP. The ZIP contains a small installer script that does everything a setup would: files, shortcuts, registry, autostart, uninstaller.

What are the requirements?

Windows 10/11 64-bit, ~500 MB free, no admin rights. Microphone optional (voice features only). Ollama optional (offline local models only).

Do I need Ollama?

No. Ollama is one option for fully offline use. There is a Settings checkbox for it. Leave it off on machines that can't run local models and the app never touches it.

Where do my API keys live?

Encrypted with Windows DPAPI in your own profile (%USERPROFILE%\.agentic_assistant). They never leave your PC and never ship in any download.

Can it control websites for me?

No. There is deliberately no browser automation in Syncopx. Open the page yourself and it can work with what is on your screen, or read public pages directly.

How do I update?

Download the new ZIP, extract, run the installer. It replaces program files and leaves your chats, keys and buttons untouched. Check this page's version number.

How do I uninstall?

Run Uninstall.bat in the install folder. Shortcuts, registry entries and program files go; your data stays unless you choose wipe.
