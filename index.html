Deployment

Three steps. No admin rights. Completely reversible.

Syncopx ships as a self-contained ZIP without opaque executable installers or forced system modifications.

  1. 01

    Download the ZIP

    One self-contained ~165 MB package, hash-verified and cryptographically signed. Extract it to any folder on your machine.

  2. 02

    Run Install-Syncopx.bat

    Stages the app to your user profile, creates Start Menu shortcuts, and registers verified boot autostart with diagnostic logging.

  3. 03

    Choose Your Model

    Run 100% offline and free with Ollama, or paste your API key for Groq, Gemini, DeepSeek, or OpenAI. All keys stay encrypted locally via DPAPI.

What the installer registers

  • %LOCALAPPDATA%\Syncopx\app — Application runtime and dependencies
  • HKCU\Software\Syncopx — Install directory and version metadata
  • HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Syncopx — Autostart with boot verification
  • Start Menu shortcut (+ optional Desktop shortcut)
  • In-app self-updater — updates seamlessly with SHA-256 validation

Uninstall anytime by running Uninstall.bat — it cleanly purges all registry keys and application files.

About Windows SmartScreen

Syncopx is distributed directly by an independent developer without paying thousands for corporate code-signing certificates. Windows may show “Windows protected your PC” on first launch. Click More info → Run anyway. You can verify the ZIP against the published SHA-256 hash before running.

Questions & Answers

Straight technical facts.

Transparent architecture, zero obfuscation.

Why is it distributed as a ZIP instead of an MSI or setup.exe?

Deliberately. Windows Defender displays harsh untrusted warnings for unsigned binary EXEs. The ZIP contains human-readable scripts (Install-Syncopx.bat, Uninstall.bat) that perform standard staging, Start Menu shortcuts, and autostart registration transparently with zero administrative privileges required.

What are the minimum system requirements?

Windows 10 or 11 64-bit, approximately 500 MB free disk space, and standard user privileges (no admin rights needed). A microphone is optional for Whistle edge voice. Ollama is optional for offline local models.

Do I have to use Ollama to run Syncopx?

No. Ollama is completely optional for users seeking 100% offline, local-only AI inference. If you prefer cloud AI, you can connect Groq, Gemini, OpenRouter, DeepSeek, or OpenAI by pasting your API key.

Where are API keys and conversation histories stored?

All credentials are encrypted with Windows DPAPI (Data Protection API) inside your personal user profile (%USERPROFILE%\.agentic_assistant). Your sessions, transcripts, notes, and local scripts remain strictly on your local disk. Zero telemetry is collected.

How do Safety Profiles and permission gates work?

Syncopx features four configurable Safety Profiles (Safe, Balanced, Unleashed, Custom). In Safe mode, all commands and file operations are strictly locked to your specified allowedDirs directory boundaries. Destructive operations prompt with permission dialogs offering Allow once, Always allow, or Reject.

How does the Browser Web Remote and Automation API work?

Syncopx includes an embedded lightweight HTTP server. Opening http://<your-ip>:8787/?token=... on your local network opens an interactive web app with voice, chat, and quick jobs. The REST API (/api/run, /api/job) allows external scripts to trigger tasks with token-based permissions and brute force IP defense.

How do in-app updates work?

Open Settings → Updates, type /update in chat, or select Check for Updates. Syncopx queries the published version.json, verifies the cryptographic signature and SHA-256 hash, downloads the delta or package, and applies it cleanly on restart without touching your conversations or keys.

How do I completely uninstall Syncopx?

Run Uninstall.bat located in your installation directory. It removes all Start Menu shortcuts, autostart registry entries, and program files cleanly. Your chat logs and API keys are preserved unless you choose the wipe option.
