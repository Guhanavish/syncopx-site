Install

Three steps. No admin. Reversible.

  1. 1

    Download the ZIP

    One self-contained package, ~163 MB, versioned and hash-published on this page. Extract it anywhere on your machine.

  2. 2

    Run the installer

    Double-click Install-Syncopx.bat. It stages the app to your user profile, creates Start Menu (+ optional Desktop) shortcuts, and configures verified autostart with boot diagnostics.

  3. 3

    Pick your AI provider

    Open Settings and choose Ollama (local, 100% offline & free) or enter your own API key for Groq, Gemini, OpenRouter, DeepSeek, OpenAI... Keys stay encrypted locally with Windows DPAPI.

What the installer registers

  • %LOCALAPPDATA%\Syncopx\app — program files
  • HKCU\Software\Syncopx — InstallDir, Version
  • HKCU\…\Run\Syncopx — autostart, verified with boot diagnostics
  • Start Menu shortcut (+ Desktop if requested)
  • In-app auto-updater — updates seamlessly from Settings → Check for Updates

Uninstall anytime with the bundled Uninstall.bat — it removes all registered components cleanly. Your chats, notes, and keys are preserved unless you choose wipe.

About the SmartScreen warning

Syncopx is open and distributed directly without a paid corporate publisher certificate, so Windows may show “Windows protected your PC” on first run. That is expected: click More info → Run anyway. Verify the ZIP first with the published SHA-256 hash above.

FAQ

Straight answers.

Is it really a ZIP, not a setup.exe?

Yes, deliberately. An installer EXE without an expensive enterprise certificate triggers harsh warnings. The ZIP contains a transparent installer script that performs everything a setup would: file staging, robocopy lock protection, shortcuts, registry registration, verified boot autostart, and an uninstaller.

What are the system requirements?

Windows 10/11 64-bit, ~500 MB free disk space, and no administrator privileges required. Microphone is optional for voice features. Ollama is optional for local offline inference.

Do I need Ollama?

No. Ollama is an optional choice for users who want 100% offline, private local AI models. If you prefer cloud providers like Groq, Gemini, or OpenRouter, simply leave Ollama off and paste your API key.

Where do my API keys and conversation histories live?

All credentials are encrypted using Windows DPAPI in your personal profile (%USERPROFILE%\.agentic_assistant). Conversation sessions, notes, programs, and subagent histories stay entirely on your local machine and never leave your PC.

How do tool approvals and security gates work?

Syncopx implements strict per-tool permission policies. Potentially destructive operations (file overwriting, command execution, system modifications) trigger permission dialogs offering Allow once, Always allow, or Reject with feedback. Read-only exploration subagents have destructive actions permanently denied.

What slash commands and keyboard shortcuts are supported?

Syncopx features keyboard-first navigation: press Ctrl+K to focus input, Ctrl+Enter to send, Ctrl+L for a fresh session, Ctrl+J to toggle the tasks panel, and Esc to stop generation. Inline slash commands include /model, /provider, /update, /tokens, /cost, /clear, /new, and /help.

Can it control apps and see my screen?

Yes. Syncopx uses local OCR to inspect active application windows and coordinates keyboard and mouse interactions across native Windows programs, Word, Settings, and installation wizards. There is deliberately no hidden browser automation.

How do updates work?

Syncopx includes built-in in-app auto-updating. Click Check for Updates in the overflow menu, run /update in the chat composer, or open Settings → Updates to query the release manifest, download updates with SHA-256 verification, and apply them on restart. You can also download new ZIPs from this site anytime; your chats, notes, and keys are always preserved.

How do I uninstall?

Run Uninstall.bat in the installation folder. All shortcuts, registry keys, and staged application files are removed cleanly. Your user data remains in your profile unless you explicitly select the wipe option.
