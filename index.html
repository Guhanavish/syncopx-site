    Deployment

    Three steps. No admin rights. Completely reversible.

    Syncopx ships as a self-contained ZIP without opaque executable installers or forced system modifications.

    01 · Download the ZIP

    One self-contained ~165 MB package, hash-verified and cryptographically signed. Extract it to any folder on your machine.

    02 · Run Install-Syncopx.bat

    Stages the app to your user profile, creates Start Menu shortcuts, and registers verified boot autostart with diagnostic logging.

    03 · Choose Your Model

    Run 100% offline and free with Ollama, or paste your API key for Groq, Gemini, DeepSeek, or OpenAI. Keys stay encrypted locally via DPAPI.

    What the installer registers: └−− %LOCALAPPDATA%\Syncopx\app (program files) └−− HKCU\Software\Syncopx (InstallDir, Version) └−− HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Syncopx └−− Start Menu (+ optional Desktop shortcut) └−− In-app self-updater (SHA-256 validation) Uninstall anytime by running Uninstall.bat — it cleanly purges all registry keys and application files.
